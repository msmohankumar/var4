💖 A Special Love Story – An Interactive Website

A personalised, romantic and interactive website created by Mohan Kumar for Priyanka. This website is designed to make a special proposal memorable through personalised messages, interactive questions, shared dreams, photographs and a heartfelt final question.

🌐 Live Website

❤️ "Click Here to Experience the Website" (https://msmohankumar.github.io/var4/)

GitHub Repository: "msmohankumar/var4" (https://github.com/msmohankumar/var4)

---

✨ Features

- Personalised Welcome Screen: A special introduction for Priyanka.
- Interactive Relationship Questions: Respond to questions about love, commitment, trust and understanding.
- My Promises: Share lifelong goals, commitment and relationship values.
- Future Together: Explore expectations about travel, home and life as partners.
- Personal Preferences: Interactive questions about hobbies and favourite food.
- Beautiful Memories: A photo gallery showcasing special moments.
- The Final Proposal: A personalised romantic proposal with a special ending.
- Responsive Design: Designed for an engaging experience across devices.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations and responsive design
- JavaScript – Interactive functionality
- GitHub – Version control and source code hosting
- GitHub Pages – Live website deployment

🚀 Run Locally

You can run this project on your computer using Visual Studio Code.

1. Clone the repository:

git clone https://github.com/msmohankumar/var4.git

2. Open the project folder:

cd var4

3. Open the folder in Visual Studio Code.

4. Open "index.html" in your browser or use the Live Server extension.

🌍 Deployment

This project is hosted using GitHub Pages.

Live URL: https://msmohankumar.github.io/var4/

To publish updates:

1. Make changes to your project files.
2. Commit and push the changes to the GitHub "main" branch.
3. GitHub Pages will automatically publish the updated website.
